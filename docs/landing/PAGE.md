# Relay.cafe Landing Page – Specification (v1)

## 1. Purpose

The landing page is:

* Informational only.
* A minimal introduction to Relay.cafe.
* A bridge to the App Store.
* Not an interactive product.
* Not a web app.
* Not a marketing funnel.

Primary goal:
→ Direct users to download the iOS app.

Secondary goal:
→ Explain the philosophy clearly and calmly.

No email capture.
No tracking scripts beyond basic privacy-respecting analytics (optional).

---

## 2. Tone & Philosophy

The landing page must:

* Match the app’s tone.
* Be minimal.
* Be calm.
* Avoid hype.
* Avoid persuasive marketing language.
* Avoid urgency.
* Avoid gamification.
* Avoid social proof.

It should feel like:

* A quiet place.
* A page.
* A note.
* Not a startup launch.

---

Left-aligned.

Content:

Relay.cafe

No background images.
No device mockups.

What It Is

---

## 4. Layout Rules

### Alignment

* All body text left-aligned.
* No centered paragraphs.
* No justified text.

### Width

* Max content width: ~720–840px.
* Generous horizontal padding on mobile (24–32px).

### Vertical Rhythm

* Large vertical spacing between sections.
* Do not compress.
* Use whitespace intentionally.

---

## 5. Typography

* System font stack (no custom branding font).
* Clean sans-serif.
* No bold blocks for emphasis except headings.
* No excessive font weight variations.

Hierarchy:

* Relay.cafe (largest)
* Section headings (medium)
* Body text (regular)
* Privacy text (slightly smaller, muted)

---

## 6. Colors

Background:

* Warm off-white (similar to app)
* No visible gradients
* No decorative patterns

Text:

* Near-black (#111 or similar)
* Secondary text muted (~70% opacity)

CTA:

* Standard App Store badge
* Do not custom-style aggressively

No accent color needed.

---

## 7. Interaction Rules

* No scroll animations.
* No parallax.
* No entrance animations.
* No auto-play elements.
* No popups.
* No modal overlays.

The page should load quietly.

---

## 8. Performance

* Lightweight.
* No heavy JS frameworks required.
* Static page acceptable.
* Can be built with simple HTML/CSS.

No need for:

* React
* Next.js
* Complex CMS
* Backend rendering

Static is preferred.

---

## 9. SEO (Minimal)

* Title: Relay.cafe – A daily anonymous message
* Description meta tag:
  Once a day, you can send a message to a stranger. Messages disappear after 24 hours.

No keyword stuffing.

---

## 10. Explicit Non-Goals

Do NOT:

* Add testimonials.
* Add user counters.
* Add “Join thousands”.
* Add email capture.
* Add countdown timer.
* Add launch waitlist.
* Add social proof.
* Add analytics-heavy tracking scripts.
* Add “About the founder” section.
* Add blog.
* Add feature grid.

This is not a marketing site.

---

## 11. Future Considerations (Not Now)

Optional later:

* Screenshot preview section.

* Press mention section.

Not in v1.
